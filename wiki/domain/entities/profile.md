## Definition

A profile is the details that identify a person in a service: their picture, name and mobile number. It belongs to one person.

## Attributes

- image — image — a picture of the person.
- name — text — the person's name.
- mobile number — phone number — a number the person can be reached on.

## Invariants

None.

## Lifecycle

A profile exists once the person is added to the service.

## Related entities

None.
